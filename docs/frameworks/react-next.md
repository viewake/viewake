# React and Next.js

`viewake-react` provides a component and hook. Install it with the core package.

```bash
npm install viewake viewake-react
```

Import the stylesheet once in your application.

```tsx
import "viewake/styles.css";
```

## React component

```tsx
import { Viewake } from "viewake-react";

export function FeatureCard() {
  return (
    <Viewake animation="fade-up" mode="replay" delay={200} duration={900}>
      <article>Feature content</article>
    </Viewake>
  );
}
```

The rendered element receives:

```html
<div data-viewake="fade-up" data-viewake-mode="replay" data-viewake-delay="200" data-viewake-duration="900">
```

## React hook

Use the hook when Viewake must observe an existing element.

```tsx
import { useViewake } from "viewake-react";

export function FeatureCard() {
  const ref = useViewake<HTMLElement>({
    mode: "once",
    threshold: 0.2,
  });

  return (
    <article ref={ref} data-viewake="fade-up" data-viewake-mode="once">
      Feature content
    </article>
  );
}
```

## Next.js App Router

The adapter includes its own `"use client"` boundary. It can be rendered from a
Server Component.

```tsx
// app/page.tsx — Server Component
import { Viewake } from "viewake-react";

export default function Page() {
  return (
    <main>
      <Viewake animation="fade-up">
        <section>Rendered by a Client Component boundary</section>
      </Viewake>
    </main>
  );
}
```

Import the CSS from the root layout.

```tsx
// app/layout.tsx
import "viewake/styles.css";

export default function RootLayout({ children }) {
  return (
    <html lang="en">
      <body>{children}</body>
    </html>
  );
}
```

## Lifecycle

The adapter creates the controller in `useEffect` and destroys it during
cleanup. No `window` or `document` access occurs during server rendering.

React Strict Mode may connect, clean up, and reconnect an effect during
development. The adapter's cleanup prevents duplicate observers.

## CSS Modules

```tsx
<Viewake animation="fade-up" className={styles.card}>
  ...
</Viewake>
```

```css
.card {
  --viewake-duration: 720ms;
  --viewake-distance: 32px;
}
```

Project styling stays in `className`; Viewake settings stay in `data-*`
attributes generated by the component.
